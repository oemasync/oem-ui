## Summary

- Horizontal page overflow (scrollX probe): **0** on every page/engine/viewport/theme. `documentElement.scrollWidth` never exceeds viewport.
- JS errors: **0**. Console: 1 recurring deprecation warning (`Deprecated API for given entry type.`), all engines/viewports, both themes — low severity, likely `PerformanceObserver`/`layout-shift` entry usage.
- Failed requests / HTTP errors on local build: **0** (the live-only Cloudflare beacon failure is environment/network, not a defect).
- Layout shift (CLS + section-top delta): **0** on all measured runs.
- Text contrast (WCAG AA, computed): no real failures. The crawler flags transparent gradient text (`span.cm-grad-text`, `code.cm-shimmer`, `span.cm-marker__content.cm-shimmer`) because computed `color` is `rgba(0,0,0,0)`; these are `background-clip: text` decorations, not AA failures. Excluded.
- Broken links: one — `/somewhere-else/` (demo link) returns 404. Intentional demo? Flagged anyway.
- Broken in-page anchors: several (listed below).
- Sticky header covers anchor targets: yes, across many sections (no `scroll-margin-top` on targets).
- Small interactive targets (<24px desktop, <44px mobile): many (listed by component).
- Media: broken images in 4 sections; missing intrinsic dimensions in 5.
