# Contrast measurements — 2026-11-27

Generated by `node scripts/measure-contrast.mjs` from `src/styles/tokens.css`.

## Method

- Source file: `src/styles/tokens.css` (commit `4bf78ae`, branch `redesign/w15-integration`).
- Theme blocks are discovered by scanning for CSS rule blocks whose body declares `--bg` (dark, light, the scoped `[data-cm-theme]` blocks, and the `@media print` block). No theme name is hard-coded.
- Tokens classified as surfaces by the same name pattern used by `tests/run.mjs` (`SURFACE_NAME`); tokens classified as inks by name (`ink`, `accent`, `focus`, `chroma-*` status hues, `foreground`, `selection-color`, `chart-c*`). Only tokens declared in a given block are scored against that block (plus the global `--focus` alias), so a block that omits a compat token is not scored against another block's fallback value.
- Paired foreground tokens (`--X-foreground`) are scored only against their own `--X` surface (resolved by name, including `--X-background` fallback), not against every surface.
- Colour values are resolved by following `var()` references (up to 8 hops), including the global `--focus: var(--ink-faint)` alias. `#rgb`/`#rrggbb`/`rgb()`/`rgba()` are parsed; `rgba()` ink values are alpha-composited over the surface they sit on before measuring (noted where it occurs).
- WCAG 2.x relative luminance + contrast ratio. Verdict thresholds: `AA` >= 4.5:1 (normal text), `AA-large` >= 3.0:1 (large text / UI components), `fail` below 3.0:1.
- Also includes the inverted hover pair `--bg` on `--ink` used by list rows and tables.

## Failing pairs (AA, normal text)

Document themes only (the scoped blocks are byte-identical and print is the
light palette). After the W16 token changes, **no pair fails AA normal text**
in either document theme: every ink token scores at least 4.5:1 on every

`--accent-dim` (now AA-large at 3.03:1 and above on every surface) is the

body text. `--chart-c4` and `--chart-c5` now clear 3:1 on the surfaces charts
are painted on (see below).

## Non-text contrast (WCAG 1.4.11)

Chart series are graphical objects and need 3:1 against the colours they sit
on. The chart component (`src/styles/components.css` `.cm-chart*`) paints
marks on `--panel` (line/area) or `--panel-nested` (bar/pie/radial/radar).

After the W16 changes both `--chart-c4` and `--chart-c5` clear 3:1 on those
surfaces in both document themes (see the Results tables above). No
mitigation is required for the mark itself; the visually hidden `<table>`,
`aria-live` tooltip and 1px `--panel` seams between adjacent segments remain
as belt-and-braces.

Conclusion: no WCAG 1.4.11 failure remains for `--chart-c4` or `--chart-c5`.
